# Changelog

## 0.1.0

- Initial VS Code implementation based on the PyQT Rust configuration application.
- Added MCU database selection and register configuration editor.
- Added NECTO-style Rust setup generation pipeline.
- Added family pin mapping and HAL implementation generation.
- Added build, flash, erase, debug, example selection and diagnostics workflows.
- Added workspace trust restriction, setup manifest and transactional setup staging.
- Added automated configuration-engine and SQLite-helper tests.
